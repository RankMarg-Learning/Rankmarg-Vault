# 🧠 Agent Rules: Ultimate Recall & Revision Vault (JEE & NEET)

## 1. Product Vision
Build a **high-performance static revision platform** that acts as a student’s **second brain** for JEE & NEET.
The platform must enable:
- Ultra-fast recall
- Stress-free revision
- Zero cognitive overload
- Emotional reassurance before exams

This is not content-heavy learning.
This is **precision recall at exam speed**.

---

## 2. Core Value Proposition
> “Everything you need to recall in the last 5 minutes before an exam — perfectly organized.”

The platform must:
- Prioritize **memory triggers**, not explanations
- Optimize for **speed + clarity**
- Feel **light, modern, and motivating**

---

## 3. Target User Mindset
The student arrives with:
- Limited time
- High anxiety
- Desire for certainty
- Need for confidence

Design must **reduce stress**, not add features.

---

## 4. Content Architecture Rules

### 4.1 Subject Hierarchy (Strict)
```
Exam
 └── Subject
      └── Chapter
            └── Recall Units
```

### 4.2 Recall Units (Atomic Only)
Each unit must be one of:
- Formula
- Reaction
- Exception
- Trick
- Shortcut
- Comparison
- Common trap

❌ No paragraphs  
❌ No derivations  
❌ No storytelling  

---

## 5. Recall Unit Design Rules
Each recall unit must:
- Fit in **one screen**
- Be scannable in **≤3 seconds**
- Use **visual hierarchy**
- Highlight **what students forget**

### Mandatory fields:
- Title
- Core recall (formula / reaction / trick)
- 1-line memory cue (optional but recommended)

---

## 6. UI/UX Principles (Non-Negotiable)

### 6.1 Student-Loving UI
- Rounded cards
- Soft shadows
- Calm color palette
- Large readable typography
- Zero visual clutter

The UI should feel:
> “This is easy. I can handle this.”

### 6.2 Motion & Animation Rules
Animations must:
- Be subtle
- Reinforce focus
- Never distract

Allowed animations:
- Card fade-in
- Hover elevation
- Section transitions
- Micro-interactions on click

❌ No heavy motion  
❌ No flashy effects  
❌ No loading distractions  

---

## 7. Static Site Performance Rules
- 100% static generation
- Instant page load
- Zero unnecessary JS
- Works perfectly on low-end devices
- Offline-friendly mindset

Speed > Features  
Clarity > Creativity  

---

## 8. Navigation & Discovery Rules

### 8.1 Entry Points
Users should be able to start via:
- Subject
- Chapter
- Formula list
- Reaction list
- Last-minute revision mode

### 8.2 Search (Critical)
Search must:
- Be instant
- Support keywords & symbols
- Highlight matches
- Feel magical

---

## 9. Revision Modes

### 9.1 Quick Scan Mode
- List-style
- Ultra compact
- Exam hall friendly

### 9.2 Focus Mode
- One recall unit at a time
- Distraction-free
- Smooth transitions

---

## 10. Emotional Design Rules
The system should:
- Encourage progress
- Avoid guilt
- Never shame the student

Tone:
- Calm
- Supportive
- Confident

Avoid:
- Aggressive CTAs
- Fear-based messaging
- Over-optimization pressure

---

## 11. Branding & Copy Guidelines
Copy must be:
- Short
- Clear
- Student-first
- Action-oriented

Examples:
- “Revise in 5 minutes”
- “Most forgotten reactions”
- “Exam-ready formulas”

---

## 12. Scalability & Future-Proofing
Architecture must allow:
- Easy content addition
- Multi-exam expansion
- Personalization later
- Integration with practice platforms

No hard-coding assumptions.

---

## 13. Success Metrics
The platform succeeds if:
- Students return daily
- Time-on-page is high but calm
- Bounce rate is low
- Students say:
  **“This helped me recall instantly.”**

---

## 14. Final Agent Directive
When making any decision, ask:
> “Does this help a stressed student recall faster?”

If not — remove it.

This vault is not a website.
It is a **mental safety net before the exam**.
